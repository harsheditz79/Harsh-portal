# 🎉 Harsh AI Birthday Portal

A futuristic AI-style birthday reply experience built using **React** and **Vite**.

Instead of sending a traditional “Thank You” message, this project creates a cinematic interactive portal featuring animated particles, scanner effects, glassmorphism UI, background music, and smooth visual effects.

---

## 🚀 Live Demo

🔗 https://harsh-portal.vercel.app/

---

## ✨ Features

- 🚀 Futuristic Entry Experience
- 💫 Animated Particle Background
- 🔮 Modern Glassmorphism UI
- 🎵 Background Music Integration
- 🎊 Confetti Celebration Effect
- 🧠 AI Boot / Loading Animation
- 📱 Fully Responsive Design
- 🌌 Cinematic Reveal Card
- ⚡ Smooth Transitions & Animations

## 📦 Installation

### 1️⃣ Clone Repository

```bash
git clone https://github.com/harshal-patil-dev/Harsh-portal.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd Harsh-portal
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start Development Server

```bash
npm run dev
```

---

## 🚀 Production Build

```bash
npm run build
```
